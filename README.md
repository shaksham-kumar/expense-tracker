# Expense Tracker

A simple command-line expense tracker built in Python. Add, view, filter, and delete your expenses,
with all data automatically saved to a JSON file so nothing is lost between sessions.

## Features

- Add an expense with amount, category, note, and date
- View all recorded expenses
- View total spending across all expenses
- Filter and view expenses by category
- Delete an expense
- Data is automatically saved to and loaded from `expenses.json`

## How to Run

1. Make sure you have Python 3 installed
2. Clone this repository:
git clone https://github.com/shaksham-kumar/expense-tracker.git
cd expense-tracker
3. Run the program:
python3 expense_tracker.py
4. Follow the on-screen menu to add, view, or delete expenses
